# IdeaFlow - Frontend Demo

Ứng dụng React (Vite) đơn giản, dùng để deploy lên Azure Static Web Apps.

## Chạy local
```
npm install
npm run dev
```

## Build production
```
npm run build
```
Kết quả build nằm trong thư mục `dist/`.

## Deploy lên Azure Static Web Apps
- App location: `/`
- Api location: (để trống)
- Output location: `dist`
